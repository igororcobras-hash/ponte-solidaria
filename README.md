# Ponte Solidária

Aplicativo web (celular e computador) que liga pessoas que precisam de ajuda a doadores, com documentos verificados, linha do tempo de prestação de contas, 39 idiomas e Modo Áudio para deficiência visual.

- Abrir o app: https://igororcobras-hash.github.io/ponte-solidaria/
- Passo a passo gratuito (GitHub Pages + Firebase Spark): veja o arquivo [LEIA-ME.md](LEIA-ME.md)

Enquanto `js/config.js` estiver com `FIREBASE_CONFIG = null`, o app roda em **modo demonstração** (sem pessoas cadastradas; o que cada visitante cria fica salvo só no aparelho dele).

Este projeto é independente do site totalcivil.com.br.
